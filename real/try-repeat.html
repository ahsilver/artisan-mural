Drag to make it shorter, so the ends overlap

This is your Pink Butterflies file as the designer uploaded it. The two copies just touch end to end, so the trees come twice and you see a line. Drag the picture to the left with the mouse (or a finger) to make the repeat shorter. The ends then overlap, and the overlap is blended so there is no line. The window on the right shows the join very zoomed in.

  • 1Drag left: shorter, the ends overlap
  • 2Watch the join in the zoom window
  • 3Keep "Blend the overlap" on
  • 4Or press "Find the repeat for me"

This is what gets printed. When you save, the website makes a new high-resolution print file that is exactly one repeat; the designer's original stays saved as an earlier version.

On the real site this tool is in the Designer studio → a design → Repeat → "Line it up by hand". It opens at full screen and works on the full-size file (for this file: 2,880 px wide; the fix made it 2,310 px, with the overlap blended).
