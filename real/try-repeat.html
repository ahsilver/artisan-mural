Drag the copy until the pattern joins

Two of your Drive files. Drag the picture left or right with the mouse (or a finger) to make the repeat shorter or longer. The window on the right shows the join very zoomed in. "Find the repeat for me" checks the file by itself, and it also tells you when a file was not made as a repeat.

On a wall: four repeats side by side

This is what gets printed. When the designer saves, the website makes a new high-resolution print file that is exactly one repeat; the original stays saved as an earlier version.

On the real site this tool is in the Designer studio → a design → Repeat → "Line it up by hand". It opens at full screen and works on the full-size file. It uses the same check as this page: it only shortens or blends a file when one position matches far better than all the others, so a picture that was never a repeat is left as it is and the designer is told to sell it as a mural.
